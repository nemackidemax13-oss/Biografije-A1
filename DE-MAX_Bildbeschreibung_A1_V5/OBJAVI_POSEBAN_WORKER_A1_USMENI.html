Poseban Cloudflare Worker „a1usmeni“

Ne diraš a1nivo! Svi mejlovi i njihove OpenAI provere ostaju u starom Workeru. Novi a1usmeni služi isključivo za glasovni razgovor prema 40 slika.

1. Napravi nov Worker

  1. Otvori Cloudflare → Workers & Pages → Create / Erstellen → Worker.
  2. Izaberi Start with Hello World ili Create Worker (naziv se može razlikovati).
  3. Upiši ime a1usmeni, zatim klikni Deploy / Bereitstellen.
  4. U novom Workeru klikni Edit code / Code bearbeiten.

2. Zalepi ovaj gotov kod

U novom Workeru klikni unutar worker.js, pritisni Ctrl+A pa Ctrl+V, a zatim Deploy / Bereitstellen.

3. Dodaj OpenAI API tajnu

U Workeru a1usmeni otvori Settings → Variables and Secrets → Add. Izaberi Secret, unesi ime nivoA1 i kao vrednost unesi svoj pravi OpenAI API ključ.

Važno: Možeš koristiti isti OpenAI API ključ kao za mejlove, ali Cloudflare ne deli automatski Secrets između Workera. Stari ključ se ne može pročitati iz postojećeg Secret polja. Ako njegovu vrednost više nemaš, u OpenAI platformi napravi novi API ključ. Ne šalji ključ u ChatGPT i nikada ga ne stavljaj u GitHub ili HTML.

4. Proveri da li radi

Proveri a1usmeni Worker — nakon objavljivanja i unosa ključa treba da piše "configured": true.

Otvori DE-MAX A1 usmeni dijalog sa 40 slika. Pritisni Počni razgovor i dopusti pristup mikrofonu.

Ako si novom Workeru dao drugo ime, u aplikaciji otvori ⚙ podešavanja i upiši njegovu HTTPS adresu.
